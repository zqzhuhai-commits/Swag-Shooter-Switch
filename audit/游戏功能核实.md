# 游戏功能核实

依据：当前游戏global-metadata.dat结构化解析的类型/方法/字段，以及用户实机截图。仅名字匹配不能证明函数实现、运行时启用或手柄可用；以下明确区分证据层级。

| 功能 | 核实结果 | 证据与限制 |
|---|---|---|
| 移动、冲刺、自动跑 | HUD及代码支持 | InGamePlayUi.AutorunOnButtonClicked/AutorunOffButtonClicked；playercontroller.autoRun/running |
| 跳跃、蹲、趴 | HUD及代码支持 | Jump/Crouching、OnCrouchButtonClicked、cameraPronePosition、proneId |
| 翻越/攀爬 | 代码存在 | Climbing/OnClimbingAction、vaultAnimationLength；不能认定任意障碍可翻越 |
| 射击、开镜、换弹、切枪 | HUD及代码支持 | WeaponsInputTrigger.OnFirePressed/OnAimPressed/OnReloadPressed/OnCycleWeaponsPressed |
| 拾取物品 | HUD及代码支持 | 用户物品列表，WeaponManager.PickUpGun、SettingScript.OnAutoPickupPressed |
| 近战武器 | HUD及代码支持 | 用户截图左下斧头，OnKnifeButtonClicked/OnAxeButtonClicked |
| 医疗、投掷物 | HUD及代码支持 | OnMedKitButtonClicked、GrenadeButtonPressed/FlashBombButtonPressed/SmokeBombButtonPressed |
| 背包/物品存储 | HUD及代码支持 | OnAmmoStoreButtonClicked/SetBagStoreItems |
| 地图 | 小地图明确存在 | 尚未据截图确认点小地图能展开完整大地图 |
| 第一/第三人称切换 | 代码存在、条件受限 | PlayerViewManager.ToggleCharacter/_canChangeView；CameraManager.GotoNextCameraMode；CameraMode含FPS/ThirdPerson/TopView；未确认本局入口 |
| 收起武器 | 代码存在、玩家入口未确认 | weaponselector.hidecurrentWeapon/unhidecurrentWeapon/RetractWeapon；也可能用于换枪/动画，不等于玩家可手动收枪 |
| 上下车、油门、倒车、转向 | HUD及代码支持 | 玩家驾驶截图与PlayerCarInteractionHandler.CarDrivingState/drivingCar |
| 自由观察/屏息/独立肩射 | 未找到明确玩家入口 | 第三方插件相关词不算本游戏功能证据 |
| 地图标记 | 未找到明确玩家入口 | 小地图标记渲染不等于玩家主动打点 |
| 单发/自动手动切换 | 未找到明确玩家入口 | AI GunScript的burst字段及OnAutomaticFireEvent不足以证明玩家可切射击模式 |
| 开门/扶人 | 未找到明确玩家入口 | 通用交互或网络复活符号不足以证明可开门/扶人 |
| 换座/鸣笛 | 未确认玩家入口 | 目前HUD只有进退、转向及退出按钮 |

不为未确认功能盲目分配触控坐标。相机切换可优先验证运行时许可和入口；地图展开、收枪也需进一步验证。
