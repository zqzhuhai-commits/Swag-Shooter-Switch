# 0.14.59 受击停滞恢复测试版

在原生 BaseScript.LateUpdate 后增加半秒采样。仅已登记、当前存活的 AI 在游戏进行期间参与；首次健康样本不认定受击。实际血量下降触发观察，最近八秒受过伤且连续约三秒未离开半米范围时，尝试附近三个单位距离的四向 NavMesh 落点；每次尝试间隔至少五秒。

优先保留原生行为，不清除翻越、闪避或动态物体状态，不改攻击目标，不瞬移。任一保护字段读取失败或导航未就绪则跳过。目标距离至少一个单位；原位置在有效安全区内时不选择区外目标。通过原 NavmeshInterface.SetDestination 直接重新提交，并恢复代理 isStopped，绕过原 MoveAI 对重复目标的跳过路径。成功后清除本次受击恢复请求，后续再受伤可以重新触发。该逻辑不依赖安全区存在，因此也适用于无安全区玩法的已登记 AI。

代码已编译，已有编队/名单 ARM64 回归、导航检查与安装包完整性检查通过；这些不覆盖 Unity 内的新恢复行为。需要实机检查受伤停滞是否减少、正常瞄准和翻越是否保留、圈内移动是否正常。受击并不要求所有 AI 立即跑动；该补偿也不能修复地图烘焙缺失或导航完全不可用。默认日志关闭；启用诊断时成功恢复记录为 AI_HIT_RECOVERY。

本版为本地测试版本，未替换 GitHub 0.14.58 正式版。
