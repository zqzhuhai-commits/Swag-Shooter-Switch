# 0.14.51 四人小队集成测试说明

仅启用经典组队模式（内部模式编号 7）。目标为 52 人、13 队、每队 4 人，玩家占第 1 队一个固定席位。

实现使用 13 个实际 Team 对象，并设置 TargetScript 及 GunScript 的敌方编号。原第二队仅作为本地 HUD 与原结算逻辑的对手汇总容器；不作为实际 AI 阵营。

死亡适配在原同步回调期间临时把死亡角色映射为本队/对手汇总编号，随后恢复实际编号。此处以及完整 Unity 对象生命周期需要实机验证。

主机验证结果见 squad-rules-0.14.51.json。测试运行编译后的 ARM64 规则，以及从生产源码提取的托管数组构造函数；托管 API 使用模拟对象，因此不证明实际 Unity 场景已正确接入。

设备日志应出现：

- `SQUAD_SETUP status=READY squads=13 size=4 population=52 ai=51`
- `SQUAD_ROSTER population=52 ai=51 squads=13 members=4x13 verified=1 local_members=4`

第二项只验证完整名册、角色与目标对象队伍编号、各队列表人数和敌方编号数组，不验证行为 AI、友伤与最终结算。

实机重点：玩家加 3 名队友、总计 52 人、敌方各队交战、消灭单个敌队不会提前结束、玩家队团灭/最后队伍存活时正确结束，再次开局可正常重建。
