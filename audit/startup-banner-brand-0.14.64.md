# 0.14.64 推广弹窗关闭按钮与图片名称替换

用户实测0.14.63的条件退出保护未解除皇家骑士白色面板阻塞，音乐继续播放；随后用户找到右上角可点击但不可见的关闭X。资源确认PurchasedBannerAds/Close Button（GameObject1496）Image12857的颜色为白色、alpha=1/255。最终本版将其RGBA改为(0.45,0.45,0.45,1.0)，保留Button12856与OnCloseButtonClicked回调全部字节。独立检查确认Image只有颜色字段16字节变化、Button无变化，按钮色彩状态没有1/255透明度。

最终交付撤回了暂时禁用EnableBanner及旧条件自动关闭的处理；推广弹窗继续显示，用户可以通过可见灰色X退出。用户随后要求先尝试修复白图，无法修复时再禁用。已找到Texture2D名为2、1920×1080的完整皇家骑士推广图（4b23bbc02e9cbd541ae85e30d63e1c2c），原格式65 ETC2_RGBA8Crunched。图像可完整解码，含对应金色枪械、背景和按钮底图；将它转换为格式4 RGBA32，重读后像素完全一致，并加入资源重定向。此为压缩纹理兼容性尝试，不证明原异常确实由Crunch引起；领取成功仍待实机确认，不清除或伪造领取记录。

五张Loadingscreen_00至04及MainmenuHeadding已通过imagegen生成中文替换图。加载图沿用原1024×1024纹理尺寸和游戏的显示布局，主页标题沿用256×256及透明背景。图片生成可能带来局部视觉差异，不宣称背景逐像素保持。原始资源只读，替换写入font-assets并加入路径重定向白名单。加载图编码为原ETC RGB格式，标题使用RGBA32保留透明度。

六张中文资源通过UnityPy保存后重读检查；再用独立原生资源表读取脚本核对对象ID、类型与数据边界，视觉检查回读的中文字和标题透明度。加上皇家骑士纹理，嵌入文件由1866增为1873。编译、NRO与NSP校验通过；推广图、领取、灰色关闭X、界面图片显示及L3切换第一/第三人称仍待实机确认。GitHub正式版0.14.58未替换。
