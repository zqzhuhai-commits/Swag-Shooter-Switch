# 0.14.53 AI、进圈与加载难度显示

精英档散布/射击停顿/战术停留系数由 0.55/0.55/0.65 改为 0.40/0.38/0.45，保留原下限与个体差异。其余难度不变。

经典单人和经典组队以有效下一圈为目标；没有有效预告圈时使用当前圈。安全范围为目标半径的 90%。目标取进圈方向上半径 60%～70% 位置，经实际 Unity NavMesh.SamplePosition_Injected 采样后，确认落点仍在目标圈内，再通过原 BaseScript.MoveAI 提交正常寻路。进圈后交还原行为。

NavMeshHit 字段顺序已从该游戏元数据确认：Position、Normal、Distance、Mask、Hit；采样缓冲区 64 字节并按 16 字节对齐，读取首个 Vector3。原生 icall 完整名称与游戏库一致。移动及冲刺函数入口的原始指令经过匹配后安装。

圈信息半秒更新；每名 AI 最多每 1.5 秒重算落脚点。动态物体交互、翻越、闪避保留原移动。采样失败或无有效圈信息时回退原移动。并非每种地图障碍都有可达路径；采样到可行走面不等于完整路径可达，效果仍待实机验证。

LoadingPanel.OnEnable 原代码读取旧资料并重写 serverText。新回调在其后写入已保存的 difficulty，并在轮询中同步；serverTitleText 使用“游戏难度”。弱引用跟踪面板，沿用既有 UI 字符串 GC 句柄。

验证：完整编译、实际本地化资源与占位符、游戏库入口匹配、导航落点几何表达式模型检查，以及 NRO/NSP 全资源哈希。主机几何模型不执行 ARM64 移动回调；无法替代实机对寻路、进圈人数、精英难度体验和加载界面显示的检查。

保留 0.14.52 提前结算与多核调度修复；本地测试版，不自动正式发布。
