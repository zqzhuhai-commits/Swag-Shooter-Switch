# 绝地精英 0.14.78 控制恢复版

作者：Xiao Fan。

0.14.77 实机反馈右摇杆与陀螺仪均不再控制视角。原因是取消了这两个输入的触摸拖动，却将增量叠加到当前持枪视角未使用的 CnControls 摄像机输入轴。本地名称匹配及函数入口检查不能证明游戏实际消费了该输入。

本版完整撤回该输入桥，包括 CnInputManager.GetAxis 的补丁、跳板、发布数据和停用视角触摸的分支。恢复 0.14.76 已有实机响应的多点触摸路径：右摇杆和陀螺仪合并到指针 17；起点 (1080,410)，活动范围 x=980～1180、y=350～470，仍在右半屏并避开拾取列表。移动指针 16 与视角指针分开。

体感仍保留 0.14.77 提高后的基础增益：较 0.14.76 提高 50%，约为 0.14.74 的 3.75 倍，单帧限幅 30 像素。按住 ZL 且实际开镜才启用，驾驶时禁用。已有 `/switch/swag-gyro.cfg` 的倍率及方向设置不变，无需重新绑定坐标或删除存档。

普通步行保持 28 位移，冲刺 75；保留性能频率请求和驾驶、第三人称显示修正。

## 验证范围

- Switch 编译和 NRO／NSP 完整性校验。
- ARM64 输入策略测试检查体感新增益、死区、限幅、重复样本和断档归零。
- 源码检查确认错误输入轴补丁与停用触摸分支均已移除。
- 实机仍需确认右摇杆转动、开镜体感与同时移动／开火。

本版优先恢复控制。恢复触摸路径后，边界回中仍可能带来周期性停顿，尚未宣称彻底解决视角流畅度。新的原生连续输入方案需要进一步核对实际使用的视角入口后再测试。
