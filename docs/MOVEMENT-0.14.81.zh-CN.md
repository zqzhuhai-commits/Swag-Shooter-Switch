# 绝地精英 0.14.81 步行／跑步控制测试版

作者：Xiao Fan，基于 0.14.80。

## 操作

- 推动左摇杆：普通步行，目标速度为原 normalspeed 的 65%。
- 短按 L3：切换跑步，使用原 runspeed；再短按一次恢复步行。
- 松开左摇杆：停止移动，保留所选步行／跑步状态。
- 长按 L3：沿用第一／第三人称切换功能。
- 驾驶模式不使用本版步行速度控制。

## 修改原因

原生 playercontroller.OnUpdate 既有持续前向输入自动加速，也会在更新后半段通过跑步分支重新写入 runspeed/running。0.14.80 只在 OnUpdate 开始时限制参数，仍可能被后半段覆盖。

本版取消 L3 对手机端“自动跑”按钮的模拟点击，由 Switch 按键状态独立决定步行／跑步。在原生选择速度之后、实际读取 speed 计算位移之前再次确定速度和 running 状态，避免先前的设置被覆盖。只作用于本地角色。

开镜、蹲伏、跳跃、爬梯、落地、换弹及开火时不强制把原生低速提升到普通行走／跑步速度；仍保留相应原生限制。退出左摇杆控制或进入驾驶后恢复捕获的参数。

保留 0.14.80 的准心渲染、第三人称换枪更新、视角连续输入以及 0.14.79 的体感方向和灵敏度。

## 本地检查

- Switch 编译。
- ARM64 执行测试：目标步行／跑步速度、原生先写入高速后的最终限速、切换至跑步、特殊状态不被强行加速。
- 位移计算前的桥接代码通过 64 组随机状态检查，验证栈对齐、寄存器与向量保存、NZCV/FPCR/FPSR 保存、四条被覆盖指令的重放，以及返回原生 speed 读取位置。
- 独立校验 NRO 和 NSP 内容完整性。

这些检查不代替实机运行。请比较“只推左摇杆”“短按 L3 后再推”“再次短按 L3 后再推”三种状态，并检查开镜、蹲伏、跳跃和上下车是否正常。
