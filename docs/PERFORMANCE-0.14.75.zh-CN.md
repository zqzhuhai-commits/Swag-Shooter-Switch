# 绝地精英 0.14.75 测试版

作者：Xiao Fan。基于用户已确认的 0.14.74 驾驶与第三人称修正版。

## 体感瞄准

体感输入的基础增益改为 0.14.74 的 2.5 倍。单帧位移上限也相应由 8 像素提高到 20 像素，避免快速转动时被旧上限截断。平滑、死区、开镜门控、驾驶禁用及松开 ZL 重置仍保留。

已有 SD 卡 `/switch/swag-gyro.cfg` 中的倍率继续生效，例如旧配置 `sensitivity_x 1.0` 和 `sensitivity_y 1.0` 也会得到本次提高后的基础增益，无须删除配置。两个倍率仍支持 0.1～5.0；默认均为 1.0。

## 步行与拾取

- 普通步行的左摇杆模拟触摸位移由 40 改为 34，输入幅度降低 15%。实际移动速度取决于原游戏的摇杆响应，需实机确认；冲刺保持原设置。
- 将视角触摸起点由 (850,330) 移至 (600,380)，活动范围限制为 x=450～760、y=200～560。此前起点与用户截图中的拾取列表重叠，列表可能捕获视角触摸。
- 保持右摇杆视角指针和拾取指针独立；增加拾取期间保留视角指针、边界不进入物品列表的启动自检。
- 第三人称保持同一人物模型时复用已缓存渲染器，避免每次输入轮询分配三份托管渲染器数组。第一人称武器相机的渲染隐藏仍保留，避免换枪重影。

上述改动针对输入冲突和不必要的分配，不代表完全消除了 Unity 在首次载入武器、材质或编译着色器时的同步停顿。

## 性能频率请求

默认启用。通过 libnx clkrst 查询系统枚举的频率，仅选择不超过以下上限的最高离散频率：

| 项目 | 请求上限 |
| --- | --- |
| CPU | 1785 MHz |
| 内存频率 | 1600 MHz |
| GPU，电池掌机 | 460.8 MHz |
| GPU，低功率供电 | 768 MHz |
| GPU，底座或系统报告供电充足 | 921.6 MHz |

供电分类每两秒检查，只有分类变化时重新请求，不持续覆盖 sys-clk 等工具。系统拒绝请求、服务不可用或频率表不兼容时继续运行游戏。诊断日志 `PERFORMANCE_CLOCK` 记录请求结果及当时实际读回频率；不能把请求值当成实机生效值。

正常退出时尝试恢复本程序改过且仍为本程序所设值的频率；系统强制结束进程时由 Horizon 或外部频率管理工具接管。没有修改电压或内存时序，也没有改变内存容量分配或启用系统保留 CPU 核心。

可选关闭：SD 卡 `/switch/swag-performance.cfg` 内容为 `enabled 0`，重启游戏后生效。

频率范围及供电限制参考：[sys-clk 官方说明](https://github.com/retronx-team/sys-clk/blob/develop/README.md)。

## 测试范围

本地编译、输入策略与可见性 ARM64 测试，以及 NRO／NSP 内嵌文件完整性检查；不包含 Switch 实际帧率测量。请实测拾取武器时持续转动右摇杆、步行与冲刺速度、体感开镜手感及掌机／底座表现。
