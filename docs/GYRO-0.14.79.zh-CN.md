# 绝地精英 0.14.79 体感调整版

作者：Xiao Fan。基于 0.14.78 的触摸视角输入方式。

- 按实机反馈反转体感横向基础映射：`-yaw` 改为 `yaw`。上下方向保持原样。
- 体感基础增益 2250→3375，比 0.14.78 再提高 50%，约为 0.14.74 的 5.625 倍。
- 单帧限幅 30→45 像素，低通平滑、死区、实际开镜门控、驾驶禁用和松开 ZL 重置不变。
- 右摇杆、步行、驾驶及第三人称设置沿用 0.14.78，没有再次启用 0.14.77 的错误输入轴桥。

原有 `/switch/swag-gyro.cfg` 灵敏度倍率继续生效。`invert_x` 依然相对于新的基础方向取反：若之前手动设为 1 来修正左右相反，应改回 `invert_x 0`。未手动调整时无需修改文件。`invert_y` 不受本次横向修正影响。

编译、ARM64 策略测试及安装包校验不等同于实机方向和手感验证。请按住 ZL 开镜后左右轻转掌机／手柄，核对水平转动方向及速度。
