# 绝地精英 0.14.83 第三人称准心校正测试版

作者：Xiao Fan，基于 0.14.82。

第三人称使用后移的 FPS 场景镜头，但原生 Utility.RectTransformToScreenSpace 使用场景投影换算 HUD 准心位置。两套相机空间不一致可能造成实际射击取点偏离屏幕中央。

本版仅当本地第三人称人物模型展示且对象为本地 LaserBeam.crossHairRectTransform 时，将转换结果的中心校正为实际 Screen.width/height 的中央，保留原矩形尺寸。第一人称、开镜、驾驶及退出对局时释放匹配对象并恢复原生路径。其他 UI 矩形不处理。

该对象用于 LaserBeam.GetCorrectRay 的瞄准射线，raycastfire 的屏幕准心分支也调用同一工具函数。未调整武器散布、后坐力、伤害、AI 或镜头高度。没有把所有子弹硬性吸附到目标。

本地校验只证明入口指令及代码编译、包完整性，不代表实机命中或所有武器均已验证。请用第三人称静止单发射击平墙，比较近中远距离的弹孔与准心中心；再切回第一人称及开镜对比。曳光线从枪口出发，近距离可能有视差，重点观察弹孔中心而非线条起点。
