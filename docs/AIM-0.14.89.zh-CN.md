# 0.14.89 实战准心黑块修复测试版

实机反馈：0.14.88 菜单四种图案正确，但切换后实战变成黑方块；再切回原样式仍黑。

本版让菜单和实战复用同一组已加载的精灵，不再动态创建另一组 Sprite。实战绑定同时使用菜单的基础 UI 材质，覆盖旧 sprite 和 overrideSprite；切换时清除 CanvasRenderer 的透明度分离贴图及旧渲染数据，随后 SetAllDirty、Rebuild(PreRender) 重建。相同样式、相同材质不会重复清空画布。

旧透明度纹理或材质残留是待实机验证的原因假设，尚不能据此声称已经确认根因或彻底修复。此版处理该渲染状态问题，而非继续更换准心图片。

实际游戏元数据校验通过：14项 Image、Graphic、CanvasRenderer 接口可用；移除 Sprite.Create 依赖。新增生产函数 ARM64 测试执行34373条指令，覆盖旧替代图、旧材质、透明度清除、清空/标脏/重建顺序、切换再切回、默认材质和空对象保护；菜单预览回归执行15802条指令通过。编译及NRO 1876项资源哈希校验通过。NSP另行独立完整性验证。

待实机检查：四种准心分别切换后的实战透明背景；切回原样式；开镜与回到第三人称；驾驶时隐藏。模拟测试不等同于Unity实际渲染测试。
