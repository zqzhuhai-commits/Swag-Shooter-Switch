# 绝地精英 0.14.74 测试版

作者：Xiao Fan。基于本地 0.14.73，保留按住 ZL 开镜时的陀螺仪瞄准。

## 本次修改

- 修正第三人称相机和陀螺仪门控错误读取驾驶状态的问题：`drivingCar` 是布尔字段，之前按对象字段读取始终无法获得驾驶状态。
- 优先判断驾驶状态，再处理第一／第三人称切换，不再把车辆镜头强制切回步行镜头。
- 驾驶时隐藏第一／第三人称的准心与武器渲染相机，只关闭 Camera 的渲染，不停用武器对象和更新脚本。
- 第三人称换枪时重新检查第一人称模型，并持续关闭第一人称武器相机的渲染，避免双枪重叠。开镜、返回第一人称和下车时恢复相关可见性。
- 第三人称相机高度由原位置加 0.15 改为加 0.40，横向偏移仍为 0.18，后移仍为 1.8。
- 复制第三人称可见层时保留原第一人称镜头的准心层设置，避免额外渲染一套准心。没有替换准心图片；若仍与以前的十字准心不同，需要实机截图进一步核对武器自身准心。

## 校验与限制

- Switch 编译通过，NRO 内 1875 个文件 SHA-256 全部匹配。
- 使用生产可见性处理代码编译 ARM64 测试：7968 条指令通过。检查反复隐藏、原生重新开启后的隐藏、对象替换与销毁、原生下车恢复不被覆盖、准心恢复等。
- 原有规则 ARM64 测试通过，7707344 条指令。
- Unity 的车辆镜头、准心样式、换枪重影、肩部遮挡和陀螺仪方向仍待 Switch 实机验证。本地检查不等同于实机通过。

## 实机重点

1. 第一人称及第三人称各上车一次，确认驾驶画面无悬浮手枪和准心，驾驶控制正常。
2. 下车后确认移动、开火、开镜与准心恢复。
3. 第三人称连续切换几种枪械，确认没有第一人称枪械重叠。
4. 第三人称走动、跑动、抬头低头，检查肩膀遮挡是否减轻。
5. 按住 ZL 开镜试用陀螺仪，驾驶时陀螺仪不控制步行视角。
