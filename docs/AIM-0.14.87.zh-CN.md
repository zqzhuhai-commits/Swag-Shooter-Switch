# 0.14.87 准心黑方块修复测试版

用户反馈 0.14.86 在设置切换准心后显示整块黑色，准心消失。用户同时提出可能绑定到错误图片。

本次修正：
- 补齐序列化 Sprite 顶点的 UV，四个区域分别映射四种图形，避免所有 UV 为零。
- 运行时读取贴图后验证名称 JF_Crosshair_Atlas、尺寸 256×64、格式 RGBA32。验证不符时不替换准心。
- 使用 Unity 原生 Sprite.Create(Texture2D, Rect, Vector2) 生成运行时四种精灵，以引擎生成的几何和 UV 供设置、选中预览与实战共用。
- 仍使用四种无描边样式，不增加黑色描边。

通过检查：四种图案不同、无黑色及描边像素、八项预览引用正确、四个 UV 区域正确；真实预览 setter 的 15802 条 ARM64 指令回归测试；编译及 NRO 1876 项资源哈希校验。

尚未验证：Unity 实机黑方块是否消失。不能仅凭资源与模拟测试声称问题已彻底解决。建议分别切换四种准心，检查设置、选中状态与实战，然后重启确认保存。

同时按要求删除 0.14.79—0.14.84 六个旧 NSP，释放约 2.92 GiB，保留 0.14.85 和 0.14.86 供回退；源码、资源及工具未清理。
