# 0.14.85 准心与第三人称曳光测试版

游戏：绝地精英；作者：Xiao Fan。提供单文件 NSP。

## 修改

- 准心设置改为四种样式：十字、圆点、圆环、十字加圆点。纯白色、无描边；选中态预览以金色表示当前选择。
- 设置预览与游戏准心使用相同精灵。移除原第五个黑色选项；游戏内覆盖原颜色着色，避免套用黑色。
- 样式选择保存到 `sdmc:/switch/swag-crosshair.cfg`，保留原设置事件。
- 第三人称曳光尝试使用可见武器的枪口位置，朝向本次命中点；无有效命中时朝向屏幕中心射线的远点。不修改伤害、散布或命中判定，也不为敌人或队友应用此视觉调整。
- 第三人称隐藏第一人称 UI 枪口闪光，避免屏幕中漂浮的闪光与实际枪口混淆；开镜返回第一人称时恢复原显示逻辑。

## 已完成验证

- devkitA64 编译通过，启用警告视为错误。
- 1876 项内嵌资源 SHA-256 与 NRO 一致。
- 四种准心图案不同，没有黑色或描边像素；八项设置预览引用与对应游戏精灵一致。
- 输入、移动桥接、驾驶显示恢复及组队规则回归通过。
- 独立核对原游戏元数据：weaponId 为 int32；get_Muzzle 返回 Transform；RaycastHit 去除装箱头后命中点、距离、碰撞体编号偏移为 0、28、40；挂钩入口使用原始指令校验。
