# 0.14.73 陀螺仪瞄准测试

默认启用：对局中按住ZL，等待游戏实际进入开镜状态后，轻轻转动掌机或手柄微调瞄准；右摇杆继续可用。松开ZL停止陀螺仪，不需要组合键。

读取真实libnx六轴传感器，支持掌机、Pro手柄、双Joy-Con（优先右Joy-Con）。不支持六轴的手柄继续使用原摇杆操作，不提供伪造传感器读数。

只有本地存活角色、实际游戏进行中、已开镜、非驾驶且按住ZL时生效；死亡、返回菜单、驾驶、暂停时停止。陀螺仪输入与右摇杆合并到现有视角触控指针，不额外占用射击／开镜指针。

采用低通平滑、微小读数死区、单帧最大位移限制；重复样本不会累加，超过100毫秒断档重置，松开ZL作为重新握持的离合。首次按住会先记录基准，避免跳动。

## 可选配置

SD卡 /switch/swag-gyro.cfg（纯文本），不存在时使用默认值。修改后重启游戏。文件内容示例：

```
enabled 1
sensitivity_x 1.0
sensitivity_y 1.0
invert_x 0
invert_y 0
```

灵敏度范围0.1～5.0。方向相反可将对应invert值改为1；enabled 0关闭。当前没有新增游戏内设置开关。
