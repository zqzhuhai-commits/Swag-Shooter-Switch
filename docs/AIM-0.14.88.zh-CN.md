# 0.14.88 准心样式初始化修复测试版

0.14.87 实机反馈：设置四个预览相同，实战仍为同一种十字线且颜色随选择改变。

实际 global-metadata.dat 确认：UnityEngine.Sprite.Create 只保留 8、7、6、5、4 参数重载，没有上一版调用的 3 参数重载。因此初始化提前返回，样式绑定没有执行，原颜色逻辑仍在运行。

改用四参数 Sprite.Create(texture, rect, pivot, pixelsPerUnit)，每单位100像素；继续生成四种无描边精灵供设置、选中预览与实战共用。

新增 verify_crosshair_api.py，核对实际游戏元数据中的重载及参数，并接入构建，拒绝不存在的接口。编译、API 检查、ARM64 预览回归、四种资源、八项预览引用、UV 及 NRO 1876 项资源哈希检查均通过。

仍需实机确认四种样式切换、预览对应关系和黑块是否消失；此版为测试版。
